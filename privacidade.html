Política de Privacidade — YouTube Diogo

Atualizada em 28 de setembro de 2026

O app "YouTube Diogo" é uma ferramenta particular de Diogo Lemos, usada apenas para publicar vídeos no próprio canal dele no YouTube (@diogolemos51). Nenhuma outra pessoa usa o app.

Que dados o app acessa

Com a autorização do dono da conta, o app usa a API de Dados do YouTube para: (1) enviar vídeos, títulos, descrições e capas ao canal; (2) ler o nome e o identificador do canal, para confirmar que está publicando no canal certo.

Como os dados são guardados

A chave de acesso fornecida pelo Google fica guardada apenas no computador do dono do canal, em arquivo protegido. Os vídeos e textos são os do próprio dono. Nada é vendido, compartilhado com terceiros ou usado para publicidade.

Uso de dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions. Ao revogar, a chave guardada deixa de funcionar e é apagada.
